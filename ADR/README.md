# ADRs

Architectural Decision Records — why a technology or design was chosen.

## Purpose

ADRs answer: **Why was a technology or design chosen?**

They contain:

- Context and problem statement
- Alternatives considered
- Decision
- Consequences (positive and negative)

## Naming Convention

```
ADR-NNNN-title.md
```

Example: `ADR-0001-event-sourcing.md`

## Process

1. Author creates ADR documenting a decision
2. Review and discussion
3. Status changes to `Accepted` or `Superseded`
4. ADRs are never deleted, only superseded

## Status Labels

- `Proposed` — Under review
- `Accepted` — Decision finalized
- `Superseded` — Replaced by a later ADR
